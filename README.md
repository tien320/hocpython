# hocpython

Repository chứa các bài tập và ví dụ Python cơ bản dùng để học và thực hành.

## Mục tiêu

- Luyện tập cú pháp Python
- Ôn lại các khái niệm lập trình cơ bản
- Theo dõi tiến trình học qua Git

## Cấu trúc chính

- [ngay1python.py](ngay1python.py): tổng hợp bài tập ngày 1
- [ngay2python.py](ngay2python.py): tổng hợp bài tập ngày 2 (đã format)
- [nhap.py](nhap.py): thử nghiệm nhanh / scratchpad
- [note.py](note.py): ghi chú kiến thức ngắn
- [notes.md](notes.md): ghi chú học tập (format rõ ràng)
- [debai.md](debai.md): đề bài các bài tập
- [README.md](README.md): tài liệu này

## Cách chạy

Chạy file tổng hợp bài tập, sau đó nhập số bài muốn chạy:

```bash
python ngay2python.py
```

Hoặc chạy từng file tương ứng:

```bash
python ngay1python.py
python nhap.py
```

## Nội dung chính đã học

- Biến và kiểu dữ liệu
- Nhập / xuất dữ liệu
- Toán tử số học và logic
- Xử lý chuỗi
- Cấu trúc điều kiện (`if/elif/else`)
- Vòng lặp (`for`, `while`)
- Hàm cơ bản và cấu trúc dữ liệu danh sách/dict
